# 루센트의 벨리스 — 열세 번째 종소리

`index.html` 하나로 동작하는 파티제 덱 빌딩 로그라이크입니다. 브라우저로 열면 바로 실행됩니다.

- **주인공과 동료 4명**은 `assets/chars/` 의 일러스트(벨리스, 옵서, 솔, 클레르)를 씁니다. 반전 처리로 거울 속 분신(역상의 벨리스)도 만듭니다.
- 적 캐릭터, 카드 일러스트, 시계 배경은 `assets/gemini.webp` 한 장에서 배경을 걷어 내고 색조를 돌리고 오려 내어 구성합니다.
- **브금도 모두 코드로 합성**합니다. 파이프 오르간, 현악, 합창, 종, 팀파니를 18개 장면별 곡으로 연주합니다.
- 크로노 아크를 본보기로 한 구조: 파티 전원의 기술이 하나의 덱이 되고, 영혼석으로 동료를 키우며, 상처(회복 불가 HP), 소모품, 유물, 지휘자 강화가 있습니다.
- 3막 + 결말 2갈래. 제미나이의 타로 카드는 뽑힐 때 30% 확률로 역방향이 됩니다.

## 구성
```
src/        sprites.js(그림 가공) music.js(브금) data.js(카드·적·이야기) engine.js(전투) ui1.js ui2.js(화면) main.js style.css body.html
assets/     gemini.webp(적·카드·배경용)  chars/(벨리스·옵서·솔·클레르)
build.py    위 모듈과 그림을 합쳐 index.html 을 만든다
```
수정 후 `python3 build.py` 로 다시 빌드합니다.

## 조작
카드 클릭(대상이 필요하면 이어서 대상 클릭) · `1`~`9` 카드 · `Enter` 턴 종료 · `C` 지휘 · `Esc` 취소
