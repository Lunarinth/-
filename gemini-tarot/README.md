# 루센트의 제미나이 — 타로 야회

`index.html` 하나로 동작하는 타로 덱빌딩 로그라이크입니다. 브라우저로 열면 바로 실행됩니다.
게임에 쓰인 그림은 단 한 장(제미나이 씨 일러스트)이며, 카드 일러스트·적 캐릭터는 모두 그 그림을 잘라 쓰거나 색상 필터를 입혀 만들었습니다.

- 에너지 3, 손패 5장. 카드는 뽑힐 때 30% 확률로 역방향이 되어 효과가 달라집니다.
- 카드를 쓸수록 운명 게이지가 차고, 가득 차면 대아르카나 · 월식(Enter/Space 턴 종료, 1~9 카드, U 대아르카나).
- 6개의 방, 마지막은 2페이즈 보스.
