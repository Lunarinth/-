# 월식록 외전 (프로토타입)

`index.html`을 브라우저로 열면 바로 실행됩니다. 빌드 과정은 없습니다.

| 키 | 동작 |
|---|---|
| ←→ / A D | 이동 |
| Space / W | 점프 (길게 누르면 높이 점프) |
| Shift / C | 대시 (공중 1회) |
| Z / J | 나이프 (↑ 누르면 대각선 위) |
| X / K | 포물선 나이프 |
| R | 재시작 |

- `src/maps.js` — 맵 정의 (`#` 벽, `P` 시작, `w` 지상 적, `f` 비행 적)
- `src/game.js` — 물리, 전투, 렌더링
- `assets/bgm`, `assets/img` — BGM/이미지 슬롯 (아직 미연결)
