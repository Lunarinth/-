# LUNARINTH — 달의 삼위일체

루센트 저택의 달의 정원. 성검사 **클레르**(초대 하녀장)가 **옵서 → 벨리스 → 루나린스** 세 보스를 차례로 넘는 2.5D 탄막 보스전 (동방식).
Three.js + Web Audio 로 만든 정적 웹 게임이며 빌드 과정이 없다.

## 실행

ES 모듈을 쓰므로 파일을 직접 열지 말고 정적 서버로 연다.

```
cd lunarinth-simulator
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

데스크톱 브라우저(키보드) 기준이다. 첫 입력 이후 오디오가 켜진다.

## 조작 (동방식)

| 입력 | 동작 |
|---|---|
| 방향키 / WASD | 이동 |
| **Z** | 샷 (누르고 있으면 연사) · 대사 넘기기 · 결정 |
| **X** | 궁극기 「성검 해방 — 징벌의 월광」 (무적 + 탄 소거 + 큰 피해). 피탄 직후 아주 짧은 유예 안에 쓰면 사망을 취소 |
| **Shift** | 저속 이동 + 피탄점 표시. 샷이 정면에 집중되고 유도 검기가 나간다 |
| Esc · P | 일시정지 · 취소 · 대사 건너뛰기 |

피탄점은 작은 붉은 점이다. 탄의 겉모양이 아니라 이 점이 닿을 때만 맞는다(그레이즈 판정은 더 넓다).

## 게임 구성

- **난이도**: EASY / NORMAL / HARD / MADNESS(루나틱). 탄수·탄속·발사 간격·보스 체력이 바뀌고, HARD 이상에서는 추가 패턴(빔 추가, 탄 추가 등)이 붙는다.
- **잔기 / 궁극기**: 잔기 3(EASY 4), 궁극기 3. 피격하면 잔기가 줄고 궁극기는 3으로 재충전된다.
- **컨티뉴**: 기본 3회. 잔기를 모두 잃으면 컨티뉴해서 **현재 단계를 처음부터** 다시 한다.
- **엔딩**: 컨티뉴 0회 클리어 = **ENDING A**(노 컨티뉴), 1회 이상 = **ENDING B**(컨티뉴).
- **스테이지**: STAGE 1 옵서 / STAGE 5 벨리스 / FINAL STAGE 루나린스. (2~4면은 비어 있다. 번호 표기는 `js/lore.js` 의 `STAGES`)
- **플레이어 선택**: 슬롯 4칸. 지금은 클레르만 있고 나머지는 빈칸(준비 중).

### 보스의 "단계" 구조

통상(nonspell)과 스킬(spell)이 번갈아 이어지고, 단계마다 체력바·제한시간이 따로 있다 (시간이 끝나도 다음 단계로 넘어간다).
통상·스킬이 시작될 때 이름이 표시되며, 스킬은 컷인과 함께 **선언 → (보스 무적, 탄 소거) → 발동** 순으로 진행된다.
플레이어의 궁극기도 같은 방식으로 이름이 선언된 뒤 발동한다.

| 보스 | 단계 수 | 구성 |
|---|---|---|
| 옵서 | 5 | 통상 「정찰 사격」 → 천체 관측 「아스트랄 옵저베이션」 → 통상 「사각 포착」 → 사각 관측 「데드 앵글」 → 성광 포격 「스타라이트 캐논」 |
| 벨리스 | 6 | 통상 「검수 개시」 → 분석 「아카식 오디트」 → 통상 「즉석 술식」 → 필사 「아케인 스크립트」 → 봉인 「리젝트」 → **라스트** 최종 판결 「파이널 베리딕트」 |
| 루나린스 | 7 | LUMINA: 통상 「초승달 부채」 → 월광 「월광우」 / UMBRA: 통상 「그림자 구슬」 → 환영 「거짓된 달」 → 월식 「월식의 장막」 / LUNA: 낙월 「달 투척」 → **라스트** 삼위일체 「트리니티 이클립스」 |

- **궁극기 저항**: 루나린스는 기본적으로 궁극기 피해가 33%로 줄고, **라스트 스킬은 완전 면역**이다. 벨리스의 「리젝트」·「파이널 베리딕트」는 궁극기를 무효화한다.
- **벨리스의 분석률**: 시간·그레이즈·궁극기 사용으로 쌓이며, 라스트 스킬의 위력(탄 수·탄속)에 비례해 반영된다. 「리젝트」는 방어막과 샷 봉인을, 「아케인 스크립트」는 이동을 둔화시키는 구속진을 쓴다.

## 코드 구조

```
js/game.js          상태 머신(타이틀 → 선택 → 스테이지 → 클리어/컨티뉴/엔딩), 충돌, 메인 루프
js/boss.js          보스 공용 기반 클래스 (단계·타이머·선언·피격·코루틴 실행기·공격 보조 함수)
js/bosses/opsir.js     STAGE 1  (def + 공격 제너레이터)
js/bosses/bellis.js    STAGE 5
js/bosses/lunarinth.js FINAL
js/player.js        클레르: 이동/샷/저속/피탄점/데스밤/궁극기
js/lore.js          설정·대사·엔딩·난이도·캐릭터·스테이지 번호
js/ui.js            타이틀/선택 화면, HUD, 스킬 선언 컷인, 대사창, 컨티뉴/엔딩/결과, 설정집
js/entities.js      탄(hold/reaim 지원), 파티클, 바닥 구역(구속진 포함), 빔, 투척체
js/audio/*          전부 절차적 합성 BGM(menu/opsir/bellis/lumina/umbra/luna/ending/…) · 효과음
```

새 보스를 추가하려면 `js/bosses/` 에 `Boss` 를 상속한 클래스와 `DEF`(단계 목록)를 만들고, `js/game.js` 의 `BOSS_ASSETS` 와 `js/lore.js` 의 `STAGES`/`SCRIPT` 에 등록한다.

## 설정 출처

- **공식 설정**(캐릭터 공식 설정 인계서)은 `js/lore.js`의 `OFFICIAL`에만 그대로 옮겼다 (루나린스). 설정집에서 볼 수 있다.
- **옵서 / 벨리스** 의 외형·직책·능력은 제작자가 제공한 설정이다 (옵서의 능력·성격은 “제안” 단계로 표기).
- 형태 순서, 루나린스의 기술명, 각 보스의 패턴, 대사, “성검을 해방한 것은 루나린스가 처음”이라는 전제는 **창작 제안**이다.
