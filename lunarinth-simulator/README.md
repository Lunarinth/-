# LUNARINTH — 달의 삼위일체

루센트 저택의 달의 정원에서 벌어지는 2.5D 탄막 보스전. 성검사 **클레르**가 루나린스를 따르는 옵서 · 벨리스 · 루나린스를 차례로 넘는다.
Three.js + Web Audio 로 만든 정적 웹 게임이며 빌드 과정이 없다.

## 실행

ES 모듈을 쓰므로 파일을 직접 열지 말고 정적 서버로 연다.

```
cd lunarinth-simulator
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

데스크톱 브라우저(키보드) 기준이다. 첫 입력 이후 오디오가 켜진다.

## 조작

| 입력 | 동작 |
|---|---|
| 방향키 / WASD | 이동 |
| Z | 샷(연사) · 대사 넘기기 · 결정 |
| X | 궁극기 「성검 해방」 (무적 + 탄 소거 + 큰 피해) |
| Shift | 저속 이동 + 피탄점 표시 (샷이 정면에 집중) |
| Esc · P | 일시정지 · 취소 · 대사 건너뛰기 |

## 게임 구성

- **스토리**: 주인 루나린스가 누군가에게 세뇌당해 저택이 클레르 파와 루나린스 파로 갈라졌다. 보스는 모두 루나린스 파이며 벨리스는 루나린스에게 광신적으로 집착한다. (세뇌의 정체와 클레르의 과거는 EXTRA에서 밝혀질 예정)
- **진행**: 스테이지마다 *문양 병사 웨이브(통상 스테이지) → 보스(통상/스킬/라스트)* 순서. STAGE 1 옵서(별·렌즈 문양), STAGE 5 벨리스(룬·서장 문양), FINAL 루나린스(달·월식 문양).
- **체력제**: 한 대 맞아도 죽지 않는다. 피격 시 체력 −1과 짧은 무적. 체력은 스테이지 시작마다 회복. 0이 되면 컨티뉴(기본 3회, 사용 시 엔딩 분기).
- **보스 체력**: 초반 보스일수록 낮다 (옵서 ×0.55 < 벨리스 ×0.8 < 루나린스). 발악기(체력이 줄수록 강해지는 것)는 **루나린스의 라스트 스킬에만** 있다.
- **BGM**: 스테이지(병사)마다 곡이 있고, 옵서·벨리스는 각자의 곡, 루나린스는 형태별(LUMINA / UMBRA / LUNA) 3곡, 여기에 얼티메이트 스킬 곡. 전부 코드로 합성한다.
- **얼티메이트 스킬 (진짜 발악)**: 루나린스(전 난이도)는 격파되는 척하다가 웃음소리와 함께 되살아나 새 BGM과 함께 5식을 시작한다. 잔기·컨티뉴·궁극기가 봉인되고 **한 번 맞으면 체력과 관계없이 즉사**. 버티거나 쓰러지면 다음 식으로 넘어간다.

  | 식 | 이름 | 시간 | 내용 |
  |---|---|---|---|
  | 1 | 신월 「무광의 천구」 | 15s | 달빛 소멸. 느린 8방향 탄막 + (10초 이후) 발사 직후에만 조준되는 큰 반달탄 |
  | 2 | 초승 「은월의 검무」 | 20s | 초승달 탄막 + 교차하는 검격(범). 시간이 갈수록 강해짐 |
  | 3 | 상현 「월광의 왕관」 | 25s | 회전하는 빛의 고리와 계속 바뀌는 안전지대, 5초마다 경고 후 낙하하는 광역 메테오(탄 없음) |
  | 4 | 만월 「광기의 세계」 | 35s | ① 24방향 고리(홀수 번째만 가속) ② 시계/반시계 나선 + 3초마다 반전(0.6초 전 은백색 점멸) ③ 가장자리에서 수렴하는 초승달 + 5발 조준탄 |
  | 5 | 종월 「삼위일체·월천붕괴」 | 40s | 모든 식 중첩 → 잠잠해짐 → 거대한 달이 내려오며 점점 빨라짐 |

  난이도는 탄 수·탄속·발사 간격만 바꾸고 시간표(틀)는 같다. (4식의 ④ 만월개화는 의도적으로 뺐다 — 그 구간은 ③이 이어받아 35초까지 진행)
- **프랙티스** (전부 기본 개방): 타이틀 → 프랙티스. 보스·병사 웨이브·단계(통상/스킬/라스트/얼티메이트)와 난이도를 골라 연습. 컨티뉴 무제한, 사망 시 같은 단계를 즉시 재시작.
- **EXTRA**: 잠금 표시만 있고 내용은 미구현. 개방 조건 — NORMAL 이상에서 노 컨티뉴 클리어, 또는 타이틀에서 `claude` 입력.

## 파일

- `js/game.js` 상태 머신(스토리/스테이지/보스/엔딩/프랙티스), 충돌, 메인 루프
- `js/stages.js` 병사 웨이브 스크립트 · `js/mobs.js` 병사(문양) 시스템
- `js/boss.js` 보스 공용 기반 · `js/bosses/{opsir,bellis,lunarinth}.js` 각 보스와 패턴 (얼티메이트 5식은 `lunarinth.js` 하단)
- `js/player.js` 체력제 플레이어 · `js/ui.js` 타이틀/프랙티스/HUD/대사 · `js/lore.js` 설정·대사·난이도
- `js/audio/*` 합성 엔진 · BGM 디렉터(스테이지곡·보스곡·얼티메이트곡) · 효과음

## 설정 출처

- **공식 설정**(캐릭터 공식 설정 인계서)은 `lore.js`의 `OFFICIAL`에만 그대로 옮겼다 (설정집에서 볼 수 있다).
- 옵서·벨리스의 일부 설정은 제공 설정, 그 외 형태 순서·기술명·패턴·대사·스토리의 세부는 **창작 제안**이다. 인계서에서 미확정인 LUMINA / UMBRA의 고유 기술은 공식으로 확정하지 않았다.
