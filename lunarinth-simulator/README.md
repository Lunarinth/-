# LUNARINTH — 달의 삼위일체

루센트 저택의 주인, 달의 여신 **루나린스**와의 2.5D 보스전. 성검사 **클레르**(초대 하녀장)가 징벌을 집행하러 온다.
Three.js + Web Audio 로 만든 정적 웹 게임이며 빌드 과정이 없다.

## 실행

ES 모듈을 쓰므로 파일을 직접 열지 말고 정적 서버로 연다.

```
cd lunarinth-simulator
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

데스크톱 브라우저(키보드/마우스) 기준이다. 첫 클릭 이후 오디오가 켜진다.

## 조작

| 입력 | 동작 |
|---|---|
| WASD / 방향키 | 이동 |
| J · Z · 좌클릭 | 성검 참격 (자동 조준, 옵션에서 자동 공격) |
| Shift · Space | 대시 (짧은 무적) |
| K · X · 우클릭 | 성검 막기: 가까운 탄을 되받아침 |
| Esc · P | 일시정지 (대사 중 Esc = 건너뛰기) |

그레이즈 50회마다 체력 1 회복(최대 2회).

## 구성

- **3페이즈**: LUMINA(초승달·빛) → UMBRA(그믐달·어둠) → LUNA(보름달·광기, 루나틱 모드). 체력 15% 이하에서 오버드라이브.
- **페이즈 전환**: 경직·슬로모션 → 대사 → 라이저 → 임팩트 + 테마(하늘/달/UI 색) 전환.
- **오디오 (전부 절차적 합성, 음원 파일 없음)**
  - `js/audio/engine.js` 버스·리버브·딜레이·컴프레서/리미터, 보이스 빌더(FM 벨, 포먼트 합창, 서브 베이스 등)
  - `js/audio/music.js` 룩어헤드 스케줄러 BGM. 씬(menu/lumina/umbra/luna/victory/defeat)마다 박자·조성·악기가 다르고 마디 경계/즉시 크로스페이드, 라이저·임팩트 스팅어, 광란 시 템포·레이어 상승
  - `js/audio/sfx.js` 효과음 40여 종(스테레오 정위, 쿨다운, 동시 발음 제한, “키키킥” 웃음 포먼트 합성)
- 렌더링: Three.js 빌보드 스프라이트 + 원근 카메라, 페이즈별 하늘 그라디언트·달(초승/신월/만월)·구름·폐허 시차.

## 설정 출처

- **공식 설정**(캐릭터 공식 설정 인계서)은 `js/lore.js`의 `OFFICIAL`에만 그대로 옮겼다. 메뉴의 “설정집”에서 볼 수 있다.
- 형태 순서, 기술명(초승달 부채, 거짓된 달 …), 패턴, 대사, “성검을 해방한 것은 루나린스가 처음”이라는 전제는 **창작 제안**이다. LUMINA / UMBRA의 고유 기술은 미확정이므로 공식으로 확정하지 않았다.
